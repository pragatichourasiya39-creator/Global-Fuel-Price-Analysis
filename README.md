
# Global Fuel Price Analysis

### A Data Visualization Project Using Tableau, Python and Flask

## 1. Project Overview

Global Fuel Price Analysis is a data analytics and visualization project that explores fuel price variations across different countries and regions.

The project focuses on understanding petrol, diesel and LPG prices, regional differences, crude oil trends, taxation patterns, income levels and subsidy policies.

Interactive Tableau visualizations and a Flask-based website are used to present the analysis and findings.

## 2. Project Objectives

- Analyze global fuel price variations.
- Compare fuel prices across different regions.
- Study fuel price trends over time.
- Examine taxation patterns across regions.
- Compare fuel prices across income levels.
- Understand the relationship between subsidies and fuel prices.
- Present findings through interactive dashboards and stories.

## 3. Technologies Used

- Tableau – Data visualization and dashboard development
- Python – Backend application
- Flask – Website integration
- HTML – Web page structure
- CSS – Website styling
- GitHub – Project version control

## 4. Project Components

### Tableau Dashboard
Interactive dashboard presenting global fuel price trends, regional comparisons and taxation indicators.

### Tableau Story
A sequence of visualizations explaining the major findings of the analysis.

### Flask Website
A website integrating the project introduction, Tableau dashboard and Tableau Story.

## 8. How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install Flask:

   pip install flask

4. Open the Template directory:

   cd Template

5. Run the Flask application:

   python App.py

6. Open the following URL in your browser:

   http://127.0.0.1:5000/
